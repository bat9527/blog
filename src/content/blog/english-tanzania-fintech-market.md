# Tanzania Fintech & Digital Banking English Map

> 这篇不是宏观市场分析长文，而是一份给金融科技从业者准备的“术语导航”。如果你在坦桑尼亚要做银行申请、持牌经营、基础存款、个人现金贷、核心系统落地或本地供应商对接，先把这些词记住，后续检索效率会高很多。

---

## 1. Why This Note Exists

如果你对坦桑尼亚不熟，最难的往往不是“没有信息”，而是不知道该搜什么词。

同样是“开银行”，本地官方材料、支付体系、KYC 供应商、移动钱包、数字贷款监管，用的并不是同一套词。你如果只搜 `digital bank Tanzania`，会拿到很多泛泛材料；但如果换成 `Bank of Tanzania licensed institutions`、`Tier 2 Microfinance Service Provider`、`Digital Lending Platform`、`NIDA verification`，信息质量会好很多。

所以这篇文章的目标很简单：

- 帮你先建立一张关键词地图
- 帮你把监管、支付、KYC、贷款、公司注册这些领域分开
- 帮你把英文缩写、官方机构名和本地高频品牌串起来
- 帮你把“下一步该搜什么”准备好

## 2. Start With These Institutions and Systems

### 2.1 Regulators and public institutions

| Term | 中文 | Why it matters |
|------|------|----------------|
| **Bank of Tanzania (BoT)** | 坦桑尼亚银行 / 央行 | 牌照、持牌机构、支付体系、消费者保护，几乎都要从这里开始查。 |
| **National Identification Authority (NIDA)** | 国家身份识别局 | 开户、eKYC、实名核验最核心的身份机构。 |
| **National Identification Number (NIN)** | 国家身份号码 | 面向自然人的身份核验关键字段。 |
| **Tanzania Revenue Authority (TRA)** | 坦桑尼亚税务局 | 税号、纳税、企业税务登记。 |
| **Taxpayer Identification Number (TIN)** | 纳税人识别号 | 公司注册、法人资料、商户资料、税务校验都会碰到。 |
| **Business Registrations and Licensing Agency (BRELA)** | 商业注册与许可局 | 公司注册、商业登记、受益所有人申报。 |
| **Beneficial Ownership (BO)** | 受益所有权 | 公司治理、法人 KYC、AML 穿透核验高频词。 |
| **Personal Data Protection Commission (PDPC)** | 个人数据保护委员会 | 数据控制者、数据处理者、跨境/本地数据处理时要关注。 |
| **Tanzania Communications Regulatory Authority (TCRA)** | 坦桑尼亚通信监管局 | USSD、短码、通信服务相关入口。 |
| **Deposit Insurance Board (DIB)** | 存款保险委员会 | 如果你做吸收存款业务，这个机构值得熟悉。 |
| **Credit Reference Bureau (CRB)** | 征信机构 / 信用信息局 | 个人贷款征信、信用信息共享的重要关键词。 |

### 2.2 Payment infrastructure terms

| Term | 中文 | Why it matters |
|------|------|----------------|
| **National Payment Systems (NPS)** | 国家支付体系 | 搜支付监管、电子货币、清算规则时很常见。 |
| **Tanzania Interbank Settlement System (TISS)** | 坦桑尼亚银行间结算系统 | 银行间高价值结算关键词。 |
| **Tanzania Automated Clearing House (TACH)** | 坦桑尼亚自动清算所 | 批量清算、低值支付、对账资料常出现。 |
| **East Africa Payment System (EAPS)** | 东非支付系统 | 区域跨境支付、东非协同场景会提到。 |
| **TANQR** | 坦桑尼亚二维码支付体系 | 二维码支付资料常见检索词。 |

## 3. Banking, Licensing, and Operating Terms

如果你们是“帮助传音申请并经营银行”，下面这些词会比泛泛的 `digital bank` 更重要。

| Term | 中文 | Notes |
|------|------|-------|
| **Banking Business** | 银行业务 | 搜监管定义时最重要的基础词之一。 |
| **Licensed Institution** | 持牌机构 | 查名单、查合规状态的标准说法。 |
| **Banking Licence / Banking License** | 银行牌照 | 搜审批要求、资本要求和设立流程。 |
| **Limited-Scope Bank** | 限定范围银行 | Tanzania 银行类别里的正式表达之一。 |
| **Microfinance Bank** | 小额信贷银行 | 如果业务模式偏普惠、小额、轻型持牌，这个词值得持续关注。 |
| **Tier 2 Microfinance Service Provider** | 第二层级小微信贷服务提供者 | Tanzania 数字贷款/现金贷监管中非常重要。 |
| **Digital Lending Platform (DLP)** | 数字贷款平台 | 查合规数字贷款、审批要求、监管通告时很关键。 |
| **Capital Requirement** | 资本要求 | 银行设立、股东准入、牌照申请都会涉及。 |
| **Fit and Proper Test** | 适格审查 | 股东、董事、高管审查高频词。 |
| **Prudential Requirement** | 审慎监管要求 | 查银行持续合规要求常用。 |
| **Financial Consumer Protection** | 金融消费者保护 | 对费用、披露、误导营销、投诉都相关。 |
| **Complaints Resolution** | 投诉处理 / 纠纷处理 | 做数字贷款和钱包支付时很敏感。 |
| **Local Incorporation** | 本地设立 / 本地注册 | 判断是否需要本地 SPV、本地实体时常用。 |

## 4. Deposit and Personal Cash Loan Vocabulary

你们现在的核心业务是**基础存款 + 个人现金贷**，所以这部分最贴近实际业务。

### 4.1 Deposit side

| Term | 中文 | Notes |
|------|------|-------|
| **Savings Account** | 储蓄账户 | 零售存款基础产品。 |
| **Current Account** | 活期账户 / 往来账户 | 日常交易账户常见。 |
| **Demand Deposit** | 活期存款 | 监管和产品材料常出现。 |
| **Fixed Deposit / Term Deposit** | 定期存款 | 存款定价和产品设计时高频。 |
| **Deposit Mobilisation** | 吸收存款 / 拉存款 | 市场拓展、增长、渠道分析中常出现。 |
| **Interest Accrual** | 利息计提 | 核心系统和产品账务常见。 |
| **Account Opening Requirements** | 开户要求 | KYC、产品条款、客户准入要配套看。 |

### 4.2 Personal cash loan side

| Term | 中文 | Notes |
|------|------|-------|
| **Personal Loan** | 个人贷款 | 最通用的个贷词。 |
| **Cash Loan** | 现金贷 | 市场和竞品检索高频词。 |
| **Mobile Loan** | 手机贷款 | Tanzania 本地非常实用的检索词。 |
| **Short-term Digital Loan** | 短期数字贷款 | 监管和媒体资料常见。 |
| **Loan Origination** | 贷款发起 | 核心信贷流程词。 |
| **Loan Application** | 贷款申请 | 客户旅程、前端流程、接口定义高频词。 |
| **Loan Disbursement** | 放款 | 钱包放款、账户放款、银行卡放款都用它。 |
| **Loan Repayment** | 还款 | 贷后运营核心词。 |
| **Outstanding Balance** | 未偿余额 | 客户展示、贷后、催收都常见。 |
| **Due Date** | 到期日 / 应还日 | 逾期判定基础字段。 |
| **Penalty Fee / Late Payment Fee** | 罚金 / 逾期费 | 消费者保护和定价披露的敏感词。 |
| **Affordability Assessment** | 偿付能力评估 | 个人信贷审批与合规高频词。 |
| **Collections / Debt Recovery** | 催收 / 债务追偿 | 贷后管理的必备术语。 |
| **Write-off** | 核销 | 不良资产处置和财务处理时常见。 |
| **Auto-debit / Auto-deduction** | 自动扣款 | 钱包贷、账户代扣、高频还款场景都会用。 |

## 5. Payments, Wallets, and Distribution Channels

在坦桑尼亚，做银行和做支付生态理解几乎是绑定的。你不能只懂银行词，而不懂钱包词。

### 5.1 Core mobile money vocabulary

| Term | 中文 | Notes |
|------|------|-------|
| **Mobile Money** | 移动支付 / 手机钱包资金服务 | 东非最基础的支付概念。 |
| **Electronic Money (e-Money)** | 电子货币 | 搜监管、钱包制度时很常见。 |
| **Mobile Wallet** | 手机钱包 | 面向用户体验和产品设计的常用词。 |
| **Agent Network** | 代理网点网络 | 东非钱包体系非常关键。 |
| **Cash-in** | 钱包入金 / 充值 | 钱包侧存入资金。 |
| **Cash-out** | 钱包提现 / 取现 | 钱包出金。 |
| **Wallet-to-Bank Transfer** | 钱包转银行 | 银行与钱包互联高频场景。 |
| **Bank-to-Wallet Transfer** | 银行转钱包 | 拉新、入金、还款都可能涉及。 |
| **Merchant Payment** | 商户支付 | C2B 商户收款高频词。 |
| **Pay Bill** | 商户收款号 / 缴费号 | 钱包支付、缴费、商户收款常见。 |
| **USSD** | 非结构化补充数据业务 | 功能机、弱网场景仍然关键。 |
| **USSD Push** | USSD 推送确认 | 支付确认、商户收款、钱包支付高频词。 |
| **ATM Cash Out** | ATM 提现 | 钱包和 ATM 联动场景常见。 |
| **Interoperable Transactions** | 互联互通交易 | 钱包互转、跨机构转账高频词。 |

### 5.2 Local brands you should recognize immediately

| Term | 中文 / 理解方式 | Notes |
|------|----------------|-------|
| **M-Pesa** | Vodacom 体系下最重要的钱包品牌之一 | Tanzania 市场理解绕不过去。 |
| **Airtel Money** | Airtel 的移动钱包体系 | 另一个主流钱包入口。 |
| **Mixx by Yas (formerly Tigo Pesa)** | Yas 的钱包体系，旧资料里常写 Tigo Pesa | 新旧品牌建议一起搜。 |
| **HaloPesa** | Halotel 的钱包品牌 | 本地常见钱包关键词。 |
| **Agent Banking** | 代理银行 | 银行线下获客、开户、存取现网络时可重点看。 |

## 6. KYC, Identity, Data, and Tax Terms

KYC 和数据合规在 Tanzania 特别容易变成真实落地问题，而不是 PPT 上的“合规模块”。

| Term | 中文 | Notes |
|------|------|-------|
| **Electronic Know Your Customer (e-KYC)** | 电子 KYC | 开户、钱包、数字贷款高频场景。 |
| **Customer Verification** | 客户核验 | 与 NIDA、供应商 API、开户流程强相关。 |
| **NIN Verification** | NIN 核验 | 本地身份核验最值得记住的表达之一。 |
| **TIN Validation** | 税号校验 | 公司、商户、法人资料处理中很常见。 |
| **Data Controller** | 数据控制者 | PDPC 语境下很重要。 |
| **Data Processor** | 数据处理者 | 与数据控制者一起出现。 |
| **Data Subject** | 数据主体 | 客户权利相关核心术语。 |
| **Data Protection Officer (DPO)** | 数据保护官 | 组织合规职责高频词。 |
| **Consent** | 同意 / 授权 | KYC、营销、数据处理都离不开。 |
| **Sanctions Screening** | 制裁筛查 | AML/KYC 流程高频词。 |
| **Politically Exposed Person (PEP)** | 政治公众人物 | 强化尽调必备词。 |
| **Ultimate Beneficial Owner (UBO)** | 最终受益所有人 | 法人 / 股东 / 公司穿透 KYC 高频词。 |
| **Data Localization** | 数据本地化 | 如果数据不能随意出境，这个词要重点追。 |
| **Cross-border Data Transfer** | 跨境数据传输 | 云部署、异地处理、第三方供应商对接都可能踩到。 |

## 8. Swahili Words Worth Remembering

有些本地材料、FAQ、营销页、支付说明会混用英文和 Swahili。记住下面几个词，检索效率会明显提高。

| Word | Meaning | Use case |
|------|---------|----------|
| **Lipa Kwa Simu** | 手机支付 | 搜商户支付、钱包支付时非常实用。 |
| **Wakala** | 代理 / 代理点 | 搜 agent network、cash-out、线下服务网点很有用。 |
| **Mkopo** | 贷款 | 搜本地贷款材料时可和 English 混搜。 |
| **Kitambulisho cha Taifa** | 国家身份证 | 搜 NIDA / 身份证资料可辅助。 |
| **Namba ya Utambulisho wa Taifa** | 国家身份号码 | 对应 NIN 检索时可辅助。 |
